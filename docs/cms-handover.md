# CMS Handover

## Where to manage content

Open `/studio` inside the app.

This is the embedded Sanity Studio for the site. Editors can create and publish blog posts without leaving the main application.

## Recommended post templates

When creating a new post, choose one of these templates:

- `Standard Article`: a straightforward blog post with a cover image and rich text body
- `Feature Story`: a richer editorial layout with hero image, intro, and modular sections
- `Guide`: best for step-by-step or structured educational content
- `Product Roundup`: best for recommendation lists and affiliate-style posts

## Authoring flow

1. Create a post from the matching template.
2. Fill in `Title`, `Slug`, `Excerpt`, `Category`, and `Published Date`.
3. Choose a `Layout Style`.
4. Add the `Main Body` for standard article content.
5. Add `Flexible Sections` for richer layouts.
6. Add `Recommended Products` only when the post needs them.
7. Publish when ready.

## Notes

- `Excerpt` powers blog cards and previews, so it should always be written intentionally.
- `Cover Image` is used in blog lists.
- `Hero Image Override` is useful for larger feature-style layouts.
- `Show Affiliate Disclosure` should be enabled for posts with recommendation links.
