# Checkout pricing

Paid Sanity products use their `price` and `currency` as the list price. A USD product keeps its USD price on the product page. Before checkout, the page shows the exact NGN amount Paystack will charge. Existing NGN products keep their NGN list price and charge amount. Free products do not request an exchange rate.

Set `CURRENCYAPI_API_KEY` in the server environment. It must remain secret. The server requests `USD` to `NGN` from CurrencyAPI's `/v3/latest` endpoint and stores the rate, provider update time, and fetch time in Firestore's `exchangeRates/USD-NGN` document. A valid cached rate is reused for 24 hours. The first request after expiry refreshes it; a Firestore lease prevents simultaneous visitors from making duplicate provider calls. Failed refreshes have a one-hour cooldown, and the server caps attempts at 200 per UTC month. If the rate is unavailable or the cap is reached, USD checkout waits for a valid rate.

The checkout page displays the USD list price and the NGN Paystack charge. The client sends the displayed amounts to `/api/paystack/initialize`; the server recalculates them from the current product and cached rate. If either amount changed, the server returns the new quote for the customer to review before retrying. The order stores the quote and the NGN amount in kobo. Paystack receives `currency: NGN`, and the payment confirmation checks the paid amount and currency against the order.

An unfinished Paystack checkout keeps its original NGN quote when reopened, so a customer does not create a second payable transaction for the same product. If that differs from the currently displayed quote, the earlier amount is shown for review before Paystack opens. Existing NGN products should be reviewed individually before changing their list prices to USD; changing a currency label does not convert the numeric price.
